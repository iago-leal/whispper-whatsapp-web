## Causa/Estratégia
Criar um script `auxiliar/ferramentas/gerar_pkg.sh` que utilize a ferramenta nativa `pkgbuild` do macOS para empacotar a pasta `auxiliar` em um `.pkg`. O pacote deve ser configurado para instalar em `~/Library/Application Support/whispper-motor`. 
Para a extensão, apontaremos o link temporariamente para o GitHub Releases, resolvendo o erro 404/corrupção.
