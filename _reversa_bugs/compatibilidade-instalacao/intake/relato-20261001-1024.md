# Relato de Bug: Instalação do Aplicativo Auxiliar falha no macOS

**Data/Hora**: 2026-10-01 10:24
**Contexto**: `compatibilidade-instalacao`

## Problema 1: Erro ao abrir o arquivo .pkg do instalador

**Relato do Usuário**:
O usuário enviou uma imagem mostrando um erro do macOS ao tentar instalar o Whispper:
> "A operação não pôde ser concluída. (com.apple.installer.pagecontroller erro -1.) Impossível abrir 'whispper-macos-apple-silicon (1).pkg'."

O usuário detalhou em seguida:
> "o problema ocorre quando se baixa o instalador ... é uma extensão. estará resolvido quando o fluxo inteiro de instalação terminar"

O usuário enviou também uma segunda imagem mostrando a tela da extensão Chrome ("Instalação Guiada" - Passo 3: Aplicativo), onde há o botão "Baixar Instalador" para o "Whispper para Mac (Apple Silicon)". A tela diz "Aguardando a instalação do aplicativo auxiliar... Assim que você executar o instalador baixado, a página avançará automaticamente."

**Evidências anexadas**:
- `erro-instalacao-pkg.png`: Print do erro do instalador do macOS.
- `passo-3-extensao.png`: Print da página da extensão (Instalação Guiada) aguardando o instalador.

**Observações (Agente)**:
- O arquivo `.pkg` (provavelmente baixado na etapa 3 da Instalação Guiada) falha ao abrir nativamente no macOS com o erro -1 de `pagecontroller`.
- O comportamento esperado é que o instalador abra, execute a instalação do app auxiliar (provavelmente o binário do motor local) e que a extensão reconheça o fim da instalação para avançar o fluxo.

## Atualização 1
**Observações Adicionais do Usuário**:
- **Hardware/OS**: Mac M1 rodando "macOS 27" (conforme relato).
- **Passos para reproduzir**: 
  1. Baixa o instalador `.pkg` pela extensão.
  2. O Mac bloqueia a abertura inicialmente informando que é um arquivo não autorizado e sugere a exclusão (comportamento típico do Gatekeeper para pacotes não assinados/não notarizados).
  3. O usuário vai em Ajustes do Sistema > Privacidade e Segurança e clica na opção para "Abrir Mesmo Assim".
  4. Ao forçar a abertura por lá, ocorre a mensagem de erro do instalador capturada no print (`com.apple.installer.pagecontroller erro -1`).

**Observações (Agente)**:
- O problema parece estar na geração do .pkg (possível ausência de signing/notarization) e estrutura interna corrompida ou mal formatada que faz o pagecontroller falhar ao tentar renderizar a interface de instalação.
- Nenhum outro problema relatado. Relato finalizado.
